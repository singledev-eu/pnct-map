# Release 0.6.0: Português / English and theme selection

2026-10-19.

- **Language:** a PT | EN toggle switches every UI string, and the basemap labels, between European Portuguese and English. The language is picked from `?lang=`, then the saved choice, then the browser.
- **Theme:** Auto / Light / Dark selection with no flash on load.
- **Placement:** both controls are in the legend header, which is the legend chip on phones.
- **iPhone Safari fix:** no zoom on focusing the search field, and the bottom UI clears the home indicator and Safari's toolbar. The bug also affected 0.5.0.

Details: [i18n + theme](0.6.0-i18n-theme.md), [review changes](0.6.0-i18n-theme-review.md), [iPhone Safari](0.6.0-ios-safari.md).

# Release 0.7.0: 3D selection

2026-11-02.

**GitHub release:** https://github.com/singledev-eu/pnct-map/releases/tag/v0.7.0 (marked **Latest**)

- **3D selection:**
  - the map tilts onto the selected concelho or parish, which rises as a slab coloured by eligibility (PNCT, neutral, or neutral with the PNCT parishes raised);
  - rims on the slab top, and nothing on the ground showing through;
  - the drill from a concelho into a parish, and the hover pop-up;
  - translucent slabs while a protected-areas overlay is on;
  - the "3D" setting, off under reduced motion.
- **Framing:** every selection is framed inside the visible area by its projected footprint, in 3D, flat and under reduced motion.
- **Search box:** it follows the selection.

Details:
- [3d-drilldown](3d-drilldown.md): first version;
- [fixes](3d-drilldown-fixes.md): after phone and desktop testing;
- [flat fit](3d-drilldown-flat-fit.md).

Decisions from the review, all kept as shipped:
- translucent slabs with overlays;
- partial concelho option (i);
- inner rims;
- light rims in dark mode (approved after the phone check);
- the large-concelho fallback;
- zoom caps parish 14 / concelho 12;
- flat mode leaves a well-framed selection alone.

## Search box fix (included in 0.7.0)

**The bug:** the box kept the last query after the selection changed by other means. Example: "Pinhel" with Erra (Coruche) selected.

**The fix:** it now shows the current selection's name, whether the selection came from search, a map click, a panel link, a page load or a hash change. It empties when the selection is cleared. Only a change of selection rewrites it, so a language switch keeps what the viewer is typing (`main.ts` `syncSearchBox`).

**e2e** `search-box.spec.ts` (3 tests, also passed 3 times in a row):
- search Pinhel → a panel link → a map click on a neighbouring parish → close;
- a URL load and a hash change to Erra (`#f=140911`);
- a language switch while typing.

## Left over

- **Dependabot alerts on `main`:** all in development dependencies, none in the shipped site.
  - Pillow and certifi in `uv.lock` (the Python pipeline; Pillow is used by `web/scripts/side_by_side.py` and the pipeline). These include critical ones.
  - vite and @vitest/mocker in `web/package-lock.json` (build and test tools; the built static site doesn't include them).

  The push reported 14; the alerts API lists more entries, counting each affected version. Worth a dependency-bump task (and re-running the full suite, plus the link snapshot).
- **Unchanged from before:** ICNF reuse terms for RNAP; concelho card v2 (contacts for the 93 non-PNCT concelhos, the yearly INE refresh).
- **Optional 3D follow-up, not done:** one slow bearing swing after a selection lands. It was rejected as a continuous drift for battery reasons and because the map would never settle.
- **Tooling note:** `web/scripts/settled.mjs` doesn't wait for paint transitions, so a screenshot right after a theme switch can catch labels mid-fade ([fixes](3d-drilldown-fixes.md), item 4).

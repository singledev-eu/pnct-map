# 0.12.0 release: nearby services (2026-11-27)

Live at https://pnct.singledev.eu. Release commit `80d181d`, annotated tag `v0.12.0`, both pushed.

## What's in it

Nearby services, from night task 11 ([report](night/11-nearby-services.md), [data](../nearby-services/DATA.md)). For each parish and concelho panel, and for any land check point, the nearest:

- SNS health centre;
- SNS emergency service;
- supermarket;
- primary and secondary school;
- pharmacy;
- train station.

Each row has the name, the road distance and the drive time. There's also an optional overlay in the legend with a "?" explainer, and new SNS and OSM credits.

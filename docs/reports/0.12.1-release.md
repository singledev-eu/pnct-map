# 0.12.1 release: verified SUB positions, fresh-checkout guard (2026-11-27)

0.12.1 is live at https://pnct.singledev.eu.
- **Production deploy:** `bb001c39` (https://bb001c39.pnct-map.pages.dev).
- **Git:** release commit `47ccb27` and annotated tag `v0.12.1`, both pushed. There's no GitHub release object, as with earlier releases.

## What changed

- **Four SUB emergency positions checked**, each against at least two independent sources. The change went through the curated `data/services/sns_urgencias.csv` and a rebuild with `uv run make services`. Evidence: [sub-verification-2026-11](sub-verification-2026-11.md).
- **Effect:** the nearest emergency service changed for 38 parishes and 6 concelhos. It's the same SUB in every case; only the distance and time changed (Lagos seat: 1 min, 0.6 km → 3 min, 2.4 km). The grid went from `grid-37e2a144` to `grid-f0407dde`.
- **Fresh-checkout guard:**
  - README has a new "Before deploying" section: `uv run make services` (and `make landcheck`) before `npm run deploy`.
  - When the grid is missing, the deploy now refuses with "…is missing (gitignored, so a fresh checkout doesn't have it). Run \`uv run make services\` in the repo root before deploying." I tested this by moving the grid directory away and running the check.
- **Cleanup:** I deleted the local branch `nearby-services` after confirming it was an ancestor of `main`. It was never pushed, so there was nothing to delete on origin. `fix/sub-verification` (this task) was fast-forwarded into `main` and deleted too.

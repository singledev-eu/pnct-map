# 0.11.0 release: legal PNCT definition, disputed parishes, PNCT Insights (2026-11-16)

Live at https://pnct.singledev.eu. Release commit `12f4836`, annotated tag `v0.11.0`, both pushed.

## What's in it

- **PNCT = the legal definition:** the Portaria 208/2017 annex plus verified amendments (none found). 1,858 parishes are shown as PNCT. Details: [pnct-legal-alignment](pnct-legal-alignment.md).
- **5 disputed parishes**, in their own style (amber hatch, dashed outline), never shown or counted as PNCT:

| CAOP 2025 | Parish | Portaria 208/2017 | IEFP 2026-02-04 |
|---|---|---|---|
| 160209 | Dem (Caminha) | listed | missing |
| 101610 | São Bento (Porto de Mós) | listed | missing |
| 010615 | Raiva (Castelo de Paiva) | not listed | listed |
| 010614 | Pedorido (Castelo de Paiva) | not listed | listed |
| 010613 | Paraíso (Castelo de Paiva) | not listed | listed |

- **PNCT Insights** (`insights/`): 25 ready data cards in EN and PT, drafted to Telegram, with a Pi timer (Tue/Fri 09:00 Lisbon) prepared but not installed. Details: [insights](insights.md), [insights-fixes](insights-fixes.md).
- **`/i/<id>` landing paths** for the Insights posts, plus optional Cloudflare Web Analytics.

# Release 0.5.0: concelho data card

2026-10-18. The concelho card covers two blocks:

- **Population (INE):** for all 278 concelhos. The 2025 estimate, the Census 2011→2021 change, density, and the ageing ratio.
- **Câmara contacts:** for the 185 PNCT concelhos. Website, mailbox, phone, urbanism page, and a PDM link with an in-force/unclear status.

It also adds the phone sheet drag handle.

Details: [phase 1](concelho-card-phase1.md), [phase 2](concelho-card-phase2.md), [PDM status](concelho-card-pdm-status.md).
